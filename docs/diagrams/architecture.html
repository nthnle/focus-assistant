Privacy and security
Audio never leaves the Pi. Wake word, speech-to-text and voice run on the Pi; the model gets text only.
Three services hold no model key. The dock, the break line and the display can’t spend money.
Phone traffic stays home. Private addresses only, a token per service, optional device allowlist.
Every service is sandboxed. Your user, never root; read-only system; no ~/.ssh; no capabilities.
