# Status page and presence

The **[status page](#status-page)** is the e-ink panel's layout in a
browser, with a status strip and a list editor under it, for your phone or
any browser on your home network (or [from anywhere](#from-anywhere), with
Tailscale). **[Presence](#presence)** tells whether you're at the desk.

Phone *use* is counted by the [desk camera](camera.md), with nothing to set
up on the phone. To talk to the coach, use [voice](voice.md) at the desk.

## How the page is protected

- It answers **private (home network) addresses only**, and your own
  devices on [Tailscale](#from-anywhere). Never the open internet.
- It needs **its own random token**, generated by `install.sh` into
  `/etc/focus-assistant/focus.env`. Requests without it get a 403.
- Requests are **plain HTTP**, so anyone on the same Wi-Fi could read the
  token in transit. Keep guests on a guest network, and ideally reserve your
  phone an IP in the router and set `FOCUS_ALLOWED_CLIENTS` to it: then only
  that phone is answered, token or not.
- The token is in the page's URL, so it is also in your browser's history
  and in any screenshot of the address bar. Anyone with the link can read
  and change your list, though not spend money or run anything: the page
  never holds the API key.
- **Rotating the token:** delete its line from `focus.env`, run
  `sudo deploy/install.sh` (it writes a new one), and update your bookmark.

Read the token with:

```bash
sudo grep FOCUS_DISPLAY_TOKEN /etc/focus-assistant/focus.env
```

The examples use `focus.local` as the Pi's address. If your phone can't
resolve `.local` names, use the Pi's IP address (`hostname -I`).

## Status page

The [e-ink panel](architecture.md#e-ink-display)'s own layout, as a live page
for any browser on your network: the latest check-in's slot and reply and
today's open items, and under them a status strip the panel doesn't have: where you are in the day (focus
until 12:00, break till 11:00, next block), the next break, the phone,
whether you're away or have a check-in waiting, and today's done count,
phone pickups and breaks. It's live: it updates within two seconds of any
change, whether from voice, the CLI, the desk camera or a check-in.

Under the strip is the **list editor**, for when voice mishears you:

- **Add** an item to today in the box at the top.
- **Tap the circle** to mark an item done; tap the green tick under "Done
  today" to undo it.
- **Tap an item's text** to reword it. Enter (or tapping elsewhere) saves,
  Escape cancels.
- **Move** sends an item to the next workday, to "later" (no date), or to
  any day you choose with **Pick a day…**, which opens your browser's date
  picker. Later items have the same menu, with **To today** to bring one
  back or a new day to reschedule it.
- **×** removes an item, after asking. Removed items stay under "Removed
  this week" for 7 days, with a **Restore** button that brings one back as
  it was. Items removed by voice land there too, including
  anything the coach removed by mistake; "bring back the dentist" works too.

While you're typing, the page holds back its live update so it doesn't
throw away what you typed, and catches up as soon as you're done.

When you mark something done after a check-in, a red line under the reply
says so straight away ("Since 16:20: done Mow the lawn"). If you marked it
by voice or the call button, the coach then rewrites that
check-in for the list as it is now, about ten seconds later. The rewrite is
only shown, never spoken, and its cost counts with the check-ins in
`focus status`. Friday's weekly review is never rewritten, and `focus done`
from the CLI or the page's editor only gets the line, because neither can
read the API key.

The `focus-page` service serves it. Enable it, then open:

```bash
sudo systemctl enable --now focus-page
```

```
http://focus.local:8765/display?k=<FOCUS_DISPLAY_TOKEN>
```

The token goes in the URL because a browser bookmark can't send a header.
Anyone with that link on your Wi-Fi can read and change your list. On an iPhone,
Share > Add to Home Screen gives it an icon.

The upper panel mirrors the e-ink display layout ([architecture.md](architecture.md#e-ink-display)).

## From anywhere

To see and edit the list away from home, put the Pi and your
phone on [Tailscale](https://tailscale.com): a free private network between
your own devices. It's encrypted end to end, nothing on your router opens,
and nobody outside your Tailscale account can reach the Pi. Don't forward
ports on the router instead: the page is plain HTTP and won't answer
public addresses anyway.

**On the Pi:**

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up            # prints a link: open it and sign in
tailscale ip -4              # the Pi's Tailscale address, 100.x.y.z
```

(If your copy predates Tailscale support, `git pull && sudo deploy/install.sh`
first: older versions of `focus-page` turn Tailscale addresses away.)

**On the phone:** install the Tailscale app, sign in to the same account,
and switch it on. Then use the Pi's Tailscale name in place of
`focus.local`, at home or away:

```
http://focus:8765/display?k=<FOCUS_DISPLAY_TOKEN>
```

(`focus` is the Pi's hostname; with MagicDNS off, use its 100.x.y.z
address.) Update your bookmark to it, and it works everywhere. On your home Wi-Fi with Tailscale off, `focus.local` still
works.

If you set `FOCUS_ALLOWED_CLIENTS`, add the phone's Tailscale address to it
too (`tailscale ip -4` on the phone, or the Tailscale admin page), or the
Pi turns it away.

## Presence

So the coach doesn't talk to an empty desk, you count as **away** once the
[desk camera](camera.md) has seen the empty chair for 5 minutes. The camera
runs from 5 minutes before each focus block to 5 minutes after it, and
while a check-in waits for you. Without a camera, or while its service
isn't running, you always count as here.

- **Check-ins wait for you to sit down**, and are written then
  ([Schedule](install.md#schedule)), so they're never said to an empty room.
- **Stretch reminders are skipped** while you're away (you're already up).
- A check-in you run by hand (`sudo systemctl start focus-checkin`) while
  away is held, and the voice service says it within 30 seconds of the
  camera seeing you back ("You missed the midday check-in. It said: ...").
  For up to 2 hours; after that it stays on the screen, unsaid.

While you're paused (`focus pause 11:00`, or "quiet until 11" to the
coach), reminders are skipped and a check-in that comes due waits for the
pause to end. See [Pausing](../README.md#using-it).

**Its blind spots:** someone else in your chair looks like you, and so may
you, standing at the desk.

Tune it with `FOCUS_AWAY_CAMERA_MIN`;
`journalctl -u focus-stretch -u focus-checkin -u focus-voice | grep -i away`
(and `focus status` for what the next check-in waits for)
shows its decisions.
